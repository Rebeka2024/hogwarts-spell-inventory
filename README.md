# 🪄 Hogwarts Spell Inventory Manager

A Python command-line application that allows users to manage a wizard's spell collection.

## Features

- Add spells
- Remove spells
- View spell inventory
- Store spell information using JSON
- Object-oriented Python design

## Technologies Used

- Python
- JSON
- File Handling
- Object-Oriented Programming

## Skills Demonstrated

- Classes and objects
- Data structures
- Input validation
- File persistence
- Problem solving

## Future Improvements

- Add spell searching
- Add user accounts
- Add a graphical interface
- Connect to a database
